# IT Support & System Administration Portfolio

**IT Support | Service Desk | Windows Administration | Active Directory | Microsoft 365 | Remote Support**

Welcome to my IT Support Portfolio! This repository contains hands-on projects and practical labs focused on IT support, system administration, troubleshooting, remote access, cloud identity management, and ticket management.

The objective of this portfolio is to demonstrate my technical knowledge, practical learning, and problem-solving skills relevant to IT Support and Service Desk roles.

## Projects

### 1. Active Directory Home Lab

**Objective:** Practice centralized user and account management in a Windows domain environment.

**Key Activities:**
- Configure an Active Directory environment.
- Create and manage domain user accounts.
- Organize users into groups.
- Practice user account administration.
- Explore Group Policy and domain management.

**Technologies:** Windows Server, Active Directory, DNS, Group Policy.

**Project Folder:** `active-directory-home-lab-main`

---

### 2. Remote Administration & Support Lab

**Objective:** Configure and troubleshoot remote administration technologies using a VirtualBox environment.

**Lab Environment:**
- Ubuntu Linux Virtual Machine
- Windows 11 Virtual Machine
- Oracle VirtualBox

**Key Activities:**
- Configure SSH for secure remote command-line administration.
- Configure RDP for graphical remote access.
- Test network connectivity between virtual machines.
- Troubleshoot remote connection issues.
- Practice remote system administration.

**Technologies:** Ubuntu Linux, Windows 11, SSH, RDP, VirtualBox.

**Project Folder:** `Remote-Administration-Support-Lab-main`

---

### 3. Microsoft 365 & Entra ID Administration Lab

**Objective:** Explore cloud identity and user administration using Microsoft 365 and Microsoft Entra ID.

**Key Activities:**
- Create and manage cloud user accounts.
- Configure and manage Entra ID groups.
- Explore Microsoft 365 Admin Center.
- Practice Multi-Factor Authentication (MFA).
- Understand cloud identity and access management.

**Technologies:** Microsoft 365 Business Premium, Microsoft Entra ID, Microsoft Admin Center, MFA.

**Project Folder:** `Microsoft-365-EntraID-Lab-main`

---

### 4. Ticker Boy – Discord Ticket Management System

**Objective:** Explore ticket management and support request handling through a Discord-based ticket system.

**Key Activities:**
- Create and manage support tickets.
- Organize user support requests.
- Practice ticket tracking and management.
- Explore support workflows and request handling.

**Technologies:** Discord, Ticket Management System, Bot Administration.

**Project Folder:** `Ticker-Boy-main`
