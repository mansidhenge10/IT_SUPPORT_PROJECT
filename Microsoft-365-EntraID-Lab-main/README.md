# Microsoft 365 & Entra ID Administration Lab

## Overview
Built a Microsoft 365 Business Premium test environment to simulate cloud identity and user administration tasks.

## Technologies Used
- Microsoft 365 Business Premium
- Microsoft Entra ID
- Microsoft Admin Center
- MFA

## Tasks Completed
- Created and managed cloud users
- Configured Microsoft Entra ID groups
- Assigned users to groups
- Managed licenses
- Configured and tested MFA
- Performed user administration tasks

## Skills Demonstrated
- Identity & Access Management
- Microsoft 365 Administration
- Entra ID Administration
- User Provisioning
- Group Management
- MFA Configuration
